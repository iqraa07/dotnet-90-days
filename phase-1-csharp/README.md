# Phase 1 — C# Fundamentals (Day 01–30)

Each day is a small, self-contained console project: `day-NN-topic/`.

Run any day:

```powershell
dotnet run --project phase-1-csharp\day-01-setup-net-10-and-hello-world
```

Topics: variables, control flow, methods, OOP (classes, inheritance, interfaces), collections, LINQ, file I/O, JSON, generics, async/await, unit testing with xUnit.

Phase project: **HelpdeskConsole** (Day 29–30).
