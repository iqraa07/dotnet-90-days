# Learning Journal

Each study day has one `day-NN-title.md` file, created by `.\day new N` from `templates/journal.md`.

Record goals, completed work, verification results, issues, and next steps. Write **What I understood** in your own words after trying the code. Keep that section empty until the owner provides a genuine reflection.

The main progress checkmark records an implemented and verified exercise. Personal reflection is tracked separately in the journal.

- `.\day done N` checks the build and requires a personal reflection.
- `.\day done N -CodeOnly` still checks the build and may leave reflection pending. Use it only when the owner explicitly requests implementation progress without a personal reflection.

Keep pending reflection clearly recorded in the journal and session notes. Use the [daily workflow](../docs/02-WORKFLOW-HARIAN.md) for verification and completion steps.
