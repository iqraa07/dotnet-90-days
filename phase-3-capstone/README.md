# Phase 3 — HelpdeskLite (Day 61–90)

A full-stack IT helpdesk ticketing application: tickets with priority and SLA, assignment to technicians, comments, attachments, a dashboard, and role-based access (Requester, Technician, Admin).

**Stack:** ASP.NET Core API · Blazor · EF Core · SQL Server · JWT · xUnit · Docker Compose · GitHub Actions

> The solution is scaffolded on Day 62 in `HelpdeskLite/`. The design document comes first, on Day 61 (`DESIGN.md`).
