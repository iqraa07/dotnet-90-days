# Phase 3: HelpdeskLite (Days 61-90)

Planned project: a full-stack IT helpdesk application with ticket priorities, service-level targets, technician assignments, comments, attachments, a dashboard, and role-based access for requesters, technicians, and administrators.

Stack: ASP.NET Core API, Blazor, EF Core, SQL Server, JWT authentication, xUnit, Docker Compose, and GitHub Actions.

Requirements and design begin on Day 61. The shared solution is created in `HelpdeskLite/` on Day 62. Follow the [day catalog](../days/README.md), [roadmap](../ROADMAP.md), and [daily progress table](../README.md#daily-progress).
